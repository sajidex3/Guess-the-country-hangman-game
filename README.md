# 🌍 Guess the Country Hangman Game

A Jupyter Notebook implementation of a Hangman-style game where users guess country names letter by letter.

This project was built as part of a programming assignment to practice:
- Conditional logic
- Loops
- String manipulation
- User input handling
- Basic game logic design

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook

---

## ▶️ How to Run

1. Clone this repository
2. Open the notebook file `P3_Villa_Colin_Sajid.ipynb`
3. Run the cells in order
4. Follow the prompts to play the game
